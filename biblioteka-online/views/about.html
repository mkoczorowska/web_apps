O aplikacji

Biblioteka online to prosta aplikacja serwerowa stworzona przy użyciu Node.js oraz Express.js.

Aplikacja pozwala przeglądać książki, wyszukiwać je oraz dodawać nowe pozycje.

Dane książek są przechowywane w pliku JSON.

Technologie

  • Node.js
  • Express.js
  • HTML
  • CSS
  • JSON
